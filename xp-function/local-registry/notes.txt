Mutating Admission Webhook (preferred for transient pods)

A mutating webhook can automatically inject a volume mount and init container into any pod that needs to trust your self-signed registry.
How it works:

    You create a ConfigMap with your CA (as before):

kubectl -n crossplane-system create configmap registry-ca --from-file=ca.crt=./docker-certs/registry.g1/ca.crt

    Write a mutating webhook that:

        Detects pods in namespaces where Crossplane functions run

        Adds:

            A volume mount: /usr/local/share/ca-certificates/registry-ca.crt

            An init container that runs update-ca-certificates (Alpine/Debian as needed)

    The webhook ensures every transient pod gets the CA installed automatically.

    Pros: works for all transient pods, fully automatic

    Cons: more complex to set up (need TLS, webhook deployment, proper RBAC)

Reference: Kubernetes Mutating Admission Webhook
https://kubernetes.io/docs/reference/access-authn-authz/extensible-admission-controllers/
